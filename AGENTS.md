# Global UI & Design System Conventions

## Facebook Straight-Edge Line Frame UI System (Facebook 直角线框风格)
All UI cards, grid containers, and modules across the entire application MUST strictly adhere to the Facebook Straight Line Frame design style:
- **Background**: Pure white (`bg-white`)
- **Border**: Classic Facebook straight-edge line border (`border border-[#E4E6EB] rounded-md`)
- **Primary Brand Color**: Facebook Blue (`#1877F2`)
- **Hover Border**: `#1877F2` or `#1877F2`/50 (`hover:border-[#1877F2]`)
- **Shadow**: Subtle light shadow (`shadow-2xs` or `shadow-xs`)
- **Density**: Neat, high-density Meta UI layout with crisp spacing and clean typography.
