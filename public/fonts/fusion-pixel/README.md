# 中文像素字体

来源：[TakWolf / Fusion Pixel Font](https://github.com/TakWolf/fusion-pixel-font)，官方 [2026.09.25 发布](https://github.com/TakWolf/fusion-pixel-font/releases/tag/2026.09.25)。本目录保留官方未修改的简体中文字形优先 WOFF2 文件，以及发布包中的 OFL 与上游许可。

| 使用组合 | 原版字体 | 文件大小 | CJK 基本区字形数量 |
| --- | --- | ---: | ---: |
| 掌机蓝 | 8px monospaced zh_hans | 369,180 字节 | 14,718 |
| 街机桃 | 10px proportional zh_hans | 411,764 字节 | 10,615 |
| 薄荷像素、原像素等 | 12px monospaced zh_hans | 666,240 字节 | 19,219 |

保留完整发布文件，未裁减为只包含预览文字的子集。已实际解码 WOFF2 并核验新组合的全部中文、英文和数字预览字形。不同尺寸的原版字库覆盖范围不同；罕见字或 emoji 继续使用系统字形。字库按使用情况由浏览器加载，不依赖第三方字体 CDN。

主许可为 SIL Open Font License 1.1，见 `OFL.txt`；来源字体对应许可见 `LICENSES/`。生产包应一并包含这些字体和许可文件。
